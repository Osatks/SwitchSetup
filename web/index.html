Questions

Is it free?

Yes, completely: no ads, no accounts, no tracking. If it saves you time, you can support it on Ko-fi.

Do I need to install anything?

No. The online builder works in any modern browser. The Windows app is optional: it adds automatic SD card detection, an eject button and backups on your PC.

What happens to files that already exist on my card?

Files with the same name are replaced with the new versions, with no errors or prompts when writing directly to the card. When extracting a ZIP yourself, choose Replace the files in the destination. Your games, saves and other files are left alone.

Windows says "Windows protected your PC" for the app. Is it safe?

That message appears for new apps that aren't code-signed yet. Click More info → Run anyway. The app is open source, and it's built automatically from the code on GitHub, so you can check exactly what it does.

Does this hack my Switch?

No. SwitchSetup only prepares the SD card. To run custom firmware you need a console that can boot payloads (an unpatched Switch in RCM mode, or one with a modchip). Follow switch.hacks.guide to learn whether yours can, and how to set up an emuMMC.

Will I get banned?

Any homebrew carries some risk. The recommended configs reduce it: they block Nintendo's servers and hide your console's serial number on emuMMC. Keep homebrew on an emuMMC and stay offline in CFW.

Will it delete my games or saves?

No. It only replaces Atmosphère, Hekate and the apps you pick. A clean update backs up the old system files to your PC first.

Does it support piracy?

No. SwitchSetup doesn't include or link to piracy tools, signature patches or game files.

Mac or Linux?

Yes: use the online builder. It works on every system. Writing straight to the SD card needs Chrome, Edge or Opera; in other browsers, download the ZIP.
